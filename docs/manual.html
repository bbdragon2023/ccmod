它能做什麼

GAMES

三款小遊戲

貪食蛇、合併方塊（2048 玩法）、踩地雷。最高分會一直保留。

AUTO-PAUSE

自動暫停

Claude 做完、要你授權、或問你問題時，遊戲立刻凍結，並跳出提示和提示音。

CHAT

跟朋友聊天

用邀請碼開聊天室，看得到彼此是不是也在等 Claude。訊息不會傳給 Claude。

THEMES

三套主題

Studio、Riso、Pocket，每套各有自己的配色和提示音。

STATUSLINE

內建 statusline

資料夾、分支、模型、花費、今日累計、5 小時額度，不用自己寫腳本。

安裝

需要準備用途怎麼確認
Claude Code 2.1.287 以上執行 modclaude --version
function hooks 開關讓 Claude Code 載入 mod見步驟 1
Bun只有聊天需要；不裝也能玩遊戲bun --version
能點滑鼠的終端機點一下遊戲區，鍵盤才會交給遊戲Terminal、iTerm2、Ghostty、kitty、WezTerm 都可以

  1. 打開 function hooks 開關

    編輯 ~/.claude/settings.json，在 env 裡加上這一行（沒有 env 就自己建一個）：

    "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" }

  2. 拿到 mod 資料夾

    有 repo 權限的話直接 clone，mod 就在裡面的 mod/ 資料夾。沒有權限的話，請朋友把 mod/ 壓縮後傳給你，解壓到任何地方都可以。

    git clone git@github.com:bbdragon2023/chatchat.git

  3. 啟動 Claude Code 並載入 mod

    claude --plugin-dir ./chatchat/mod

    進去之後輸入 /chatchat，能打開面板就代表裝好了。

  4. （選用）安裝 Bun，聊天要用

    curl -fsSL https://bun.sh/install | bash

第一次使用

  1. 輸入 /chatchat，右側會出現 chatchat 面板。

  2. 用滑鼠點一下面板裡的遊戲區，鍵盤就交給遊戲了。

  3. 用 ↑↓ 選遊戲，按 Enter 開始。

  4. 想回去打字給 Claude，按 Esc。

終端機寬度至少 110 欄時，面板會貼在右側；比較窄時，面板會出現在提示框上方。

玩遊戲

Claude 開始工作約 5 秒後，提示框上方會出現「要玩一下嗎？」的橫條，用滑鼠點「玩一下」就會打開面板。這裡刻意不設快捷鍵，所以你在提示框打字不會誤觸。

遊戲按鍵紀錄
貪食蛇方向鍵或 WASD 移動 · R 重來最高分
合併方塊方向鍵滑動 · R 重來最高分
踩地雷方向鍵移動 · Enter 翻開 · F 插旗 · R 重來。第一下一定不會踩到雷最快秒數
任何遊戲Q 回選單 · Esc 回提示框

Claude 做完時

遊戲會立刻凍結，同時跳出提示並播放提示音。按 Enter 關掉面板、回去看結果；按 Z 再玩 30 秒。每個回合只能延一次，下一個回合照樣會暫停。

Claude 要你授權或問你問題時，不能延。

遊戲會凍結，按 Esc 回到 Claude 的授權選單處理就好。這樣可以避免「玩到忘記按允許，Claude 卡在那裡好幾分鐘」。

跟朋友聊天

聊天需要一台電腦當聊天伺服器，通常由一個人開，其他人連進來。每個人都需要 Claude Code、chatchat mod 和 Bun。

開房的人

  1. 在你的電腦開聊天伺服器。它會列出朋友可以連的位址：192.168… 給同一個 Wi-Fi 或區網的人用，100.… 是 Tailscale 位址，給不在同一個網路的人用。

    /chatchat host

  2. 開房。它會給你一行字，原封不動傳給朋友就好。

    /chatchat invite 週末 vibe
開房的人的 Claude Code 要保持開著。

聊天伺服器會跟著你的 session 一起關掉。第一次有人連進來時，macOS 可能會問是否允許 bun 接受連線，請選「允許」。

加入的人

把收到的那一行貼進 Claude Code 的提示框按 Enter，再打開聊天分頁：

/chatchat join BU8E-KBVV-GESY ws://192.168.x.x:8787  # 換成朋友傳給你的那一行

聊天時

  • 面板上方有「遊戲／聊天」兩個分頁按鈕，點「聊天」切過去。在最下面的輸入框打字，按 Enter 送出。
  • 最上面會顯示朋友現在在做什麼，例如「▲ 小美 · 等 Claude 中」。
  • 面板關著時，新訊息只會讓提示框上方的橫條顯示「● 2 則未讀」，不跳面板、不發出聲音。
  • 暱稱預設用你的 git 名字，可以用 /chatchat nick 阿哲 改掉。
  • 下次打開 Claude Code，會自動回到上次的聊天室。不想要了就用 /chatchat leave，邀請碼外流的話再開一組新的。

主題

三套主題只換外觀和提示音，按鍵和暫停規則完全一樣，你的選擇會被記住。點下面的按鈕可以預覽「Claude 做完了」在每套主題裡長什麼樣子。

/chatchat theme studio

終端機的字型是你自己設定的，mod 沒辦法換字型，所以主題的變化在配色、符號和版面上。

statusline

chatchat 會在提示框下方顯示一行狀態。你如果已經有自己的 statusline，預設的 auto 模式只會補上 ◆ chatchat 那段，不會重複顯示。

段意思開關名稱
📁目前資料夾dir
⚡bun 版本（預設關閉）bun
🌿git 分支，有未提交的改動時加 *branch
🤖模型model
💸這次 session 的花費cost
💰今天所有 session 加起來的花費daily
⏰5 小時額度還剩多久。用掉 70% 以上加 ⚠，90% 以上加 🔴limit
◆Claude 計時、在線人數、未讀數chatchat
 
/chatchat statusline full   # 或 auto · off；單獨開關：/chatchat statusline bun on

這行只能放純文字，沒辦法上顏色，所以額度警告用 ⚠ 和 🔴 符號表示。

指令總表

所有 /chatchat 指令都只在你自己的電腦上執行，不會送給 Claude，也不會花任何 token。

指令作用
/chatchat打開面板（遊戲分頁）
/chatchat chat打開面板（聊天分頁）
/chatchat close關掉面板
/chatchat help列出所有指令
/chatchat theme [名稱]查看或切換主題：studio · riso · pocket
/chatchat statusline [模式]auto · full · off
/chatchat statusline <段> on|off單獨開關某一段
/chatchat host [port]在這台電腦開聊天伺服器，預設 8787
/chatchat server <ws://…>改用別人開的聊天伺服器
/chatchat invite [房名]開聊天室，拿邀請碼
/chatchat join <碼> [ws://…]加入聊天室；不帶碼就重新連回上次的房間
/chatchat nick <暱稱>改暱稱
/chatchat leave離開聊天室

隱私與安全

  • 聊天訊息不會進入 Claude 的上下文。朋友傳什麼都只顯示給你看，所以沒辦法透過聊天訊息叫你的 Claude 做事。
  • 訊息裡的終端機控制字元會被清掉，連結只顯示成文字，不會自動打開。
  • 朋友看不到你的專案、分支、花費或 Claude 在做什麼，只看得到「在線上」或「等 Claude 中」。
  • statusline 只顯示在你自己的畫面上。
  • 聊天伺服器只看得到邀請碼的雜湊值，看不到邀請碼本身。本機的控制通道權限是 600，只有你自己的帳號能用。
聊天內容沒有端對端加密。

同一個網路裡，知道邀請碼又知道伺服器位址的人都能加入。只適合跟信任的朋友在私人網路（家裡、公司、Tailscale）上使用。

疑難排解

按鍵沒反應，字都跑到提示框

先用滑鼠點一下遊戲區。按 Esc 之後要再點一次。

輸入 /chatchat 沒有反應

確認 CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 有設定，而且有用 --plugin-dir 載入 mod。

說「終端機太窄」

把視窗拉寬，面板會自己出現。

沒有提示音

提示音目前只支援 macOS。

聊天顯示「需要 Bun」

安裝 Bun（curl -fsSL https://bun.sh/install | bash），再輸入 /chatchat join。

朋友連不上

依序檢查：① 朋友跟你在同一個網路，或改用 Tailscale 位址 ② macOS 防火牆有允許 bun ③ 開房的人的 Claude Code 還開著 ④ 位址的 port 沒打錯。

一直顯示「重新連線中」

聊天伺服器關掉了，或網路斷了。伺服器回來後會自己連上，也可以輸入 /chatchat join 立即重試。

目前的限制

  • 遊戲畫面只支援終端機，Claude Code 桌面版和 VS Code 版還不行。
  • 一定要用滑鼠點一下，遊戲才收得到按鍵，因為 mod API 沒有自動取得焦點的方法。
  • 聊天的每個人都需要 Claude Code 加這個 mod，不用 Claude Code 的朋友還沒辦法加入。
  • 勿擾（專注）模式、復古主機遊戲（WASM-4、Game Boy 自製遊戲）還在規劃中。
