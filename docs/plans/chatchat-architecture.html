Claude Code mod · 架構研究 · 2026-10-03

chatchat：等 Claude 的時候，聊天、玩遊戲

在 Claude Code 終端機裡加一個側邊面板。Claude 在工作時可以跟朋友聊天或玩小遊戲，Claude 一做完就自動暫停並叫你回來。

先講結論
  • 做得到。Claude Code 的 mod 系統能開面板、收鍵盤、畫像素，也能知道 Claude 何時開始、何時結束。
  • 遊戲這半邊已經有人做了（cc-arcade）。我們的差異是跟朋友聊天和合法的復古主機遊戲。
  • 任天堂沒有開源任何遊戲。「任天堂風」只能用開源模擬器搭配授權明確的自製遊戲（homebrew）、用開源幻想主機 WASM-4，或者自己寫。
  • 這對你的影響：建議分三階段做。先做單人小遊戲（一兩天），再做聊天（核心價值），最後才做復古模擬器（最炫也最花時間）。

整體長什麼樣子

總共兩塊。mod 住在 Claude Code 裡面，負責畫面和時機。橋接程式（bridge）是 mod 自己啟動的一個本機小程式，負責 mod 做不到的兩件事：即時連線（WebSocket）和跑模擬器。

Pane 是終端機右側的面板。Client 是面板裡自己跑計時器、自己收按鍵的小程式，遊戲迴圈就放在這裡，所以按鍵反應快。Supabase Realtime 是 Supabase 的即時廣播服務，內建「誰在線上」功能，省得自己架伺服器。

什麼時候玩、什麼時候叫你回來

這是整個 mod 最重要的規則。前例幾乎都踩過同一個坑：玩到忘記回去，結果錯過 Claude 的提問。所以暫停和提醒由程式強制執行，不靠自制力。

stateDiagram-v2
  [*] --> 閒置
  閒置 --> Claude工作中: 你送出指令
  Claude工作中 --> 遊戲中: 開遊戲（或跳出提示問你要不要玩）
  遊戲中 --> 需要你: Claude 做完 / 要你授權 / 問你問題
  Claude工作中 --> 需要你: Claude 做完
  需要你 --> 閒置: 你回到提示框
  需要你 --> 遊戲中: 選「再玩一下」（下次照樣暫停）

提醒方式有三種：畫面角落的小提示（toast）、提示音，以及狀態列上的「Claude 工作中 0:42」計時。

遊戲從哪裡來：三層，由易到難

第 1 層 · Phase 1

自己寫的小遊戲

貪食蛇、2048、踩地雷，用文字格子畫。完全沒有授權問題，一兩天就能做好。

風險：低
第 2 層 · Phase 3

WASM-4 幻想主機

開源的「假想遊戲機」（ISC 授權）：160×160 像素、4 種顏色，每款遊戲只是一個小檔案。它的規格剛好塞得進終端機。

風險：低（每款遊戲要確認授權）
第 3 層 · Phase 3

Game Boy / NES 自製遊戲

用開源模擬器 binjgb（MIT）或 jsnes（Apache），只跑授權明確的社群自製遊戲，來源是 Homebrew Hub。這就是你要的「任天堂風」。

風險：低至中

任天堂相關：哪些能碰、哪些不能

法院的立場大致是「寫模擬器合法，散布遊戲 ROM 違法」。2024 年的 Yuzu 案以 240 萬美元和解，案由是破解 Switch 的加密，不是模擬本身。同年 Ryujinx 在任天堂接觸後停止開發。以下不是法律意見，商業上架前要找律師。

做法風險為什麼
自己寫的遊戲、WASM-4 開源遊戲低完全不涉及任天堂的智慧財產
開源模擬器加上授權已確認的自製 ROM低至中模擬本身站得住，風險在於看錯授權，或在產品名稱裡用了任天堂商標
把 GPL 授權的模擬器包進 mod中不是任天堂的問題，而是 GPL 會要求整個 mod 也開源。改成讓使用者自己安裝的外部程式就能避開
名稱或圖示用「Nintendo、Mario、Tetris」中至高商標和外觀（trade dress）會被追究，Tetris 尤其積極
「自備 ROM」功能中技術上合法，但很容易被認為在鼓勵盜版，v1 不做
內建或自動下載商業任天堂 ROM高直接侵權，絕對不做

已經有人這樣做：idea 參考

cc-arcadeClaude Code mod，/arcade 開 9 款遊戲，回合結束時自動暫停；有一隻寵物會隨你跑測試、commit 而長大。MIT 授權。借：暫停時機、把 Claude 的工作事件變成遊戲獎勵。這是最接近的前例。
pi-nes在 Pi coding agent 裡跑 NES 模擬器，用 kitty 圖片協定顯示，不附 ROM。MIT 授權。借：證明「等 agent 時玩 NES」可行，以及顯示畫面的方法。
claude-snake純 Bash 貪食蛇，用 hooks 在另一個視窗自動開關。借：完全不用 mod API 的退路。
claude-arcadeClaude 一執行工具就自動開遊戲，做完自動收掉。借：自動開關的節奏。
claude-code-discord-status · claude-rpc把 Claude Code 的工作狀態顯示在 Discord 上。借：「朋友現在在等 Claude」的線上狀態設計。
Claude Code Channels（官方）把 Telegram、Discord 等外部訊息推進 Claude session 的機制。借：v2 再考慮做「把這則訊息交給 Claude」。v1 刻意不讓朋友訊息進到 AI，避免有人透過聊天操控你的 Claude。
awesome-claude-code-mods · claudemods.aiClaude Code mod 的清單和市集。借：上架通路，以及觀察其他 mod 的做法。

分三階段做

Phase 1 · 單人版

狀態列、提醒、3 款小遊戲

先驗證自己會不會真的在等 Claude 時拿來用。

Phase 2 · 核心差異

邀請碼聊天室、朋友狀態

找 2 到 3 個朋友實測，目標是訊息延遲在 1 秒內。

Phase 3 · 加分項

WASM-4、Game Boy、NES 自製遊戲

最炫也最花工，看 Phase 2 的回饋再決定要不要做。

還沒確定、要實作時才知道的事

  • mod 裡面能不能直接跑 WebAssembly？如果可以，WASM-4 就能搬進 mod，少一個橋接程式。
  • 側邊面板大約只有 60 到 80 欄寬，WASM-4 畫面要縮一半才放得下，好不好看要實測。
  • 在 tmux 裡，kitty 圖片協定常常被擋掉，這時會自動降級成半格字元。
  • 產品問題：只給自己和固定幾個朋友用，還是要上架給大家用？這會決定要不要做帳號和檢舉功能。
