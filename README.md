# chatchat

Claude Code mod：等 Claude 工作的時候，玩小遊戲、跟朋友聊天；Claude 一做完或需要你，它會叫你回來。

- **使用說明書：** [mod/README.md](mod/README.md)
- **快速開始：** 先把 `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1` 加進 `~/.claude/settings.json` 的 `env`，然後執行 `claude --plugin-dir ./mod`，再輸入 `/chatchat`
- **設計與計畫：** [docs/plans/](docs/plans/)
